`Collection` is a typed wrapper around a single collection in a database.

```py
db = client.db("default")
items = db.collection("items")
```

## Schema and document migrations (client-side)

The driver supports optional schema parsing and client-side document migrations (API parity with `@liorandb/driver`).

### `col.set_schema(schema, version)` / `col.setSchema(schema, version)`

```py
class ItemSchema:
    def parse(self, value):
        return value

items.set_schema(ItemSchema(), version=1)
```

### `col.add_migration(migration)` / `col.addMigration(migration)`

```py
items.add_migration(
    {
        "from": 1,
        "to": 2,
        "migrate": lambda doc: {**doc, "qty": int(doc.get("qty", 0))},
    }
)
```

## Inserts

### `await col.insert_one(doc)` / `await col.insertOne(doc)`

```py
doc = await items.insert_one({"sku": "A", "qty": 1})
print(doc.get("_id"))
```

### `await col.insert_many(docs)` / `await col.insertMany(docs)`

```py
docs = await items.insert_many([{"sku": "B", "qty": 1}, {"sku": "C", "qty": 2}])
```

### `await col.insert_many_stream(docs)` / `await col.insertManyStream(docs)`

Streams NDJSON to the server and returns a count.

```py
count = await items.insert_many_stream([{"sku": "D", "qty": 1}, {"sku": "E", "qty": 2}])
print(count)
```

## Finds

### `await col.find(filter=None, options=None)`

```py
results = await items.find({"qty": {"$gte": 1}}, options={"limit": 50})
```

You can also embed options in the filter under `__options` (TS parity with `extractFindPayload()`), and the driver will normalize `sortBy`/`sortDir` into `sort`.

### `await col.find_one(filter=None, options=None)` / `await col.findOne(...)`

```py
one = await items.find_one({"sku": "A"})
if one is None:
    print("not found")
```

## Updates

### `await col.update_one(filter, update, options=None)` / `await col.updateOne(...)`

```py
updated = await items.update_one({"sku": "A"}, {"$set": {"qty": 2}})
print(updated)
```

### `await col.update_many(filter, update)` / `await col.updateMany(...)`

```py
res = await items.update_many({"qty": {"$lt": 0}}, {"$set": {"qty": 0}})
print(res)
```

## Deletes

### `await col.delete_one(filter)` / `await col.deleteOne(filter)`

```py
deleted = await items.delete_one({"sku": "A"})
print(deleted)
```

### `await col.delete_many(filter)` / `await col.deleteMany(filter)`

```py
res = await items.delete_many({"sku": {"$in": ["B", "C"]}})
print(res)
```

## Counts

### `await col.count(filter=None)`

```py
n = await items.count({"qty": {"$gte": 1}})
print(n)
```

### `await col.count_documents(filter=None)` / `await col.countDocuments(...)`

Alias for `count()`.

```py
n = await items.count_documents()
```

## Aggregation

### `await col.aggregate(pipeline=None)`

```py
pipeline = [
    {"$match": {"qty": {"$gte": 1}}},
    {"$group": {"_id": "$sku", "total": {"$sum": "$qty"}}},
]
rows = await items.aggregate(pipeline)
print(rows)
```

## Indexes

```py
indexes = await items.list_indexes()
```

### `await col.create_index(field, unique=False)` / `await col.createIndex(field, options=None)`

```py
await items.create_index("sku", unique=True)
await items.createIndex("qty", options={"unique": False})
```

### `await col.create_text_index(field, options=None)` / `await col.createTextIndex(field, options=None)`

```py
await items.create_text_index("name", options={"language": "en"})
```

```py
await items.drop_text_index("name")
```

```py
opts = await items.get_options()
```

## Server-side document migration config

These endpoints manage server-side migration configuration for a collection.

### `await col.get_doc_migrations()` / `await col.getDocMigrations()`

```py
print(await items.get_doc_migrations())
```

### `await col.set_doc_migrations(config)` / `await col.setDocMigrations(config)`

```py
await items.set_doc_migrations({"enabled": True})
```

### `await col.test_doc_migration(doc)` / `await col.testDocMigration(doc)`

```py
print(await items.test_doc_migration({"sku": "A", "qty": 1}))
```
